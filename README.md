# microCT Phantom Analysis

MATLAB code for the analysis of micro-CT phantom data acquired at different tube voltages.

## Contents
- microCT_analysis.m – main analysis script
- circleCenterMask.m – auxiliary function for center detection

## Requirements
- MATLAB R2025a 
- NIfTI toolbox

## Usage
Run `microCT_analysis.m` after placing the reconstructed NIfTI files in the working directory.
